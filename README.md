# TİKO Telefon App
TİKO Barkod'un telefon uygulaması (PWA). **Sadece 3 ekran:** 🔎 Fiyat Gör (+stok), 🛒 Satış, 📋 Stok Sayım. Bulutla birleşmeye hazır mimari: `docs/SENKRON.md`. Kurulum: `docs/KURULUM.md`. Test: `npm test`.
Ana TİKO kodundan bağımsızdır (kendi klasörü/dalı); veri alışverişi katalog JSON ↔ sayım CSV ile, sonra bulut ile.
